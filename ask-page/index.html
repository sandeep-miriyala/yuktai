Ask this page

A side panel that answers questions about the page you are reading, from the page itself, and highlights where each answer came from. Search runs in Rust compiled to WebAssembly. Nothing you type or read leaves your device.

Source on GitHub
  • Keyboard: Ctrl + /
  • Search core: Rust → WebAssembly
  • Requests made while you ask: 0

Try it

Open the panel and ask anything about this page. Some questions to start with:

  • How do I install it?Finds the Installation section and highlights it.
  • సంక్రాంతి మూడవ రోజు ఏం చేస్తారు?Telugu question, Telugu section.
  • What fields are in the form?Reads labels only, never what you type.
  • What is the refund policy?Not on this page, so it says so.

Installation

Install the package with npm and mount the panel once when your app starts. It works with React, Next.js, Astro and plain HTML.

npm install @yuktishaalaa/ask-page
import { mountAskPage } from "@yuktishaalaa/ask-page"
mountAskPage({ modes: ["fast", "balanced"] })

No build step? Add one script tag. The launcher button appears in the bottom right corner.

<script src="https://cdn.jsdelivr.net/npm/@yuktishaalaa/ask-page/dist/ask-page.global.js" defer></script>

Modes

Visitors choose how much work their device does. Site owners decide which modes are offered.

Ask page modes
ModeSearchAnswerDownload
FastRust BM25 keywordsBest sentences, quotedAbout 100 KB
BalancedKeywords plus meaning (multilingual embeddings), merged with RRFChrome built-in AI if availableAbout 118 MB, once
BestSame as BalancedChrome built-in AI, or WebLLM if the site enables itMore, once

Privacy

The panel never reads what you type into forms: values, passwords and rich-text editors are skipped before anything else sees the page. Page text and questions stay on your device. There are no analytics on questions and no tracing. On pages that look signed-in, nothing is saved at all.

The only download is the model for Balanced and Best mode, after you agree. It carries no page data.

Accessibility

Text is 17 pixels (18 for Telugu) and grows with A+. Every button is at least 44 pixels. The panel works with a keyboard and screen readers: new answers are announced, Escape closes the panel and focus returns to where you were. Dark and light themes follow your system, and Windows high contrast is supported.

Frequently asked questions

Does it need an API key?

No. Everything runs in the browser. There is no server and no key.

Which browsers work?

Fast mode works in every modern browser. Balanced mode needs WebAssembly and about 118 MB of space. Chrome's built-in AI answers appear when Chrome has its model ready.

Can AI agents use it?

Yes. Ask page registers read-only WebMCP tools (ask_page, get_page_outline, get_suggested_questions) that browser agents can call. Agents can read answers but never click, type or submit.

How do I remove downloaded data?

Open Settings in the panel and choose Clear saved data or Remove model.

Troubleshooting

If the panel does not appear, check that the script loads and that your Content Security Policy allows blob: workers and WebAssembly ('wasm-unsafe-eval'). Without them Ask page still works, more slowly, on the page thread.
