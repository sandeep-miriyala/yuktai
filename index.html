YUKTISÁRATHI · yuktai v5.3.4

Accessible, agentic web apps, in your browser

One open-source toolkit for Next.js, React and plain HTML: a data grid you can talk to, small agents that test and explain a page, WCAG accessibility fixes and 163 icons. No API keys and no yuktai servers.

Open the live demo → Source on GitHub npm package

“Not a tool, but a torch for your inner Mahabharata.”

What's inside

  • Agentic data grid

    Ask your data in plain English: filters, totals, unusual rows and multi-step tasks.

  • Page agents

    QA tester with 15 WCAG checks, accessibility copilot, form and design review, page Q&A.

  • Accessibility engine

    WCAG 2.2 fixes in the browser, voice commands in English and Telugu. Every fix can be undone.

  • Ask page

    A side panel that answers questions from the page itself and highlights the source. Rust search, on-device AI, Telugu.

  • 163 icons

    One icon set for Next.js, React and plain HTML, with outline and filled styles.

Use it on any page

<script src="https://cdn.jsdelivr.net/npm/@yuktishaalaa/yuktai@5/vanilla/index.min.js"></script>

Next.js and React: npm install @yuktishaalaa/yuktai
