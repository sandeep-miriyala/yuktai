Why YuktAI

Most web apps leave out screen-reader users and Indian-language users. YuktAI doesn't.

  • ♿

    Accessible by default

    WCAG 2.2 checks and fixes, keyboard support and screen-reader labels built in. Every fix can be undone.

  • 🦀

    Rust-fast data grid

    Search and sort in WebAssembly. 10 lakh rows in one smooth list, sorted in under a second.

  • 🇮🇳

    Indian languages

    10,00,000 number format, correct Telugu and Indic sorting, voice input in 22 Indian languages.

  • 🤖

    Agents, when you want them

    Talk to your data, ask your page, and optional LangGraph agents with a Python API in new apps.

Start in a minute

Only Node.js is needed. Rust and Python are optional extras.

New app

A ready Next.js app with the grid, accessibility and icons.

npm create yuktai@latest my-app
cd my-app
npm run dev

Next.js or React

Add it to an app you already have.

npm install @yuktishaalaa/yuktai

Plain HTML

One script tag. No build step, works with jQuery too.

<script src="https://cdn.jsdelivr.net/npm/@yuktishaalaa/yuktai@5/vanilla/index.min.js"></script>
