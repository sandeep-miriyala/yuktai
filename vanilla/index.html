1. Agentic data grid

Search, sort, page, select and export, plus two ways to ask: the question bar (filters, BI answers, multi-step tasks) and the grid assistant (custom rules → phrase parser → grid tools, with voice). Keyboard: Tab into the table, then arrow keys, Home/End, Ctrl+Home/End, Page Up/Down, Space to select, Enter to open.

3. Ask questions without a grid

createAgenticGrid() is the vanilla useAgenticGrid. Use it with any table you already have: it gives back gridData, highlightIds, the answer, a BI table and task steps.

4. Page tools (AgenticPanel)

Copilot, QA report, Forms, Design, Ask page and Voice, mounted inline with yuktai.mountAgenticPanel("#page-tools"). The same panel opens from the button. The practice form below has deliberate problems for the tools to find.

Practice form (deliberate problems)

Insert a form with one unlabeled field and an email without an autocomplete hint, then run “Forms”, “QA report” or “Ask page → Which fields have no label?”. Turn on → “Auto-fix page” to watch the engine repair new content.

5. Accessibility engine

The button runs the yuktai engine (wcagPlugin): WCAG auto-fixes, high contrast, dark mode, reduced motion, 44×44 targets, colour-blind filters, dyslexia font, text size 80–130%, skip links and speak-on-focus. Choices are saved on this device.

yuktai.apply({ highContrast: true, fontSizeMultiplier: 1.2 })
yuktai.reset()
yuktai.getSettings()   // { highContrast, darkMode, reduceMotion, largeTargets, dyslexiaFont, colorBlindMode, fontSizeMultiplier, … }

6. Core functions (same as npm)

// Grid with everything on
const grid = yuktai.renderGrid("#staff", {
  data: rows,
  rowKey: "id",
  columns: [
    { key: "name", label: "Name" },
    { key: "salary", label: "Salary", type: "number", render: (v) => "₹" + Number(v).toLocaleString("en-IN") },
    { key: "joined", label: "Joined", type: "date" },
    { key: "status", label: "Status", type: "badge" },
  ],
  locale: "en-IN",            // or "te-IN" (Telugu UI and messages)
  theme: "default",           // high-contrast | dark | color-blind | dyslexia
  view: "auto",               // table | card | auto
  pagination: { pageSize: 20, showSizeChanger: true, sizeOptions: [10, 20, 50, 100] },
  agentic: { examples: ["salary over 1 lakh", "anything unusual?"] },   // question bar
  ai: true, inputLanguage: "te-IN",                                    // assistant: chat + voice
  customRules: [{ name: "high-earners", phrases: ["high earners", "ఎక్కువ జీతం"],
    execute: async ({ executeTool }) => (await executeTool("filter", { key: "salary", operator: "greaterThan", value: 100000 })).message }],
  webmcp: true, toolName: "my_staff_grid",
  onWebMCPStatusChange: (s) => console.log(s.state),
  onRowClick: (row) => openDetails(row),
  onSelectionChange: (keys) => console.log(keys),
  onAgentResult: (r) => console.log(r.message),
})

await grid.ask("salary over 1 lakh in Hyderabad")   // "… row(s) found. Showing rows where …"
await grid.executeTool("sort", { key: "salary", direction: "desc" })
grid.highlight(["1001", "1002"]); grid.getSelectedRows(); grid.exportCSV()
grid.setTheme("dark"); grid.setView("card"); grid.refresh(newRows); grid.destroy()

// Page agents
yuktai.runQaAudit().score
yuktai.auditToMarkdown(yuktai.runQaAudit())
yuktai.reviewForms({ seniorFriendly: true })
yuktai.reviewDesign({ minFontSize: 16 })
await yuktai.askAboutPage("Which fields have no label?")
const copilot = yuktai.createA11yCopilot({ onUpdate: console.log }); copilot.scan(); copilot.applyAllFixes(); copilot.undoAll()
const voice = yuktai.createVoiceA11yController({ lang: "te-IN" }); await voice.handle("పెద్ద అక్షరాలు")
yuktai.mountAgenticPanel("#tools", { defaultTab: "qa", voiceLang: "te-IN" })
