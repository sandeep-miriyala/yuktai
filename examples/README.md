# YuktAI 6.0 examples

| Folder | What | Run |
|---|---|---|
| `html/` | Script tag on a plain page | open `index.html` |
| `react/` | `mountAssistant()` in a Vite + React app | `npm install && npm run dev` |
| `next/` | `<YuktaiAssistant />` in a Next.js App Router layout | `npm install && npm run dev` |

Each page is Telugu with one English line: the Assistant sets `lang="te"` on the page and `lang="en"` on the English part by itself.
